𓃥 遊戲介紹：白六麻將推銷樂
「滑動指尖，智取雀壇！」
這不是傳統的麻將遊戲，而是一場空間邏輯的挑戰。在充滿綠意的麻將桌布上，玩家需要巧妙移動牌塊，讓相同的牌相遇並消除。遊戲主角是可愛的台灣犬「白六」，牠將全程陪伴您完成挑戰！
核心特色
• 物理手感移動：模擬真實推牌感，路徑順暢且支援多格移動。
• 嚴謹消除邏輯：採「二對二」成對消除機制，保證開局必有解。
• 雙重挑戰模式：提供 144 張「完整模式」與隨機 2 花色的「精簡模式」。
• 視覺動態效果：消除時帶有華麗的破碎動畫與震動反饋感。
🎮 玩法說明
1. 目標 (Objective)
在有限的空間內，將場面上所有的麻將牌全數消除，且牌堆（Deck）剩餘數量歸零。
2. 移動規則 (Movement)
• 選取與移動：點擊一張牌，系統會以亮黃色框示出所有可移動的「空格」。
• 路徑限制：牌塊只能在「空格」中水平或垂直移動。
• 一鍵到位：若該位置只有唯一路徑，點擊目標格即可快速推移至該處。
3. 消除機制 (Elimination)
• 鄰接消除：當您移動牌塊後，只要該牌的上下左右任一側出現「相同花色」的牌，兩張牌便會觸發破碎動畫並消失。
• 成對優先：為了確保遊戲結算不留單張，系統嚴格執行「一對一」消除。即使移動後周圍有三張相同牌，也只會消除移動的那張與其中一位鄰居。
• 連鎖補牌：每當牌被消除，系統會從牌堆隨機補入新牌。若新牌落下後恰巧形成鄰接對子，會自動觸發「連鎖消除」。
4. 遊戲流程
• 開局：系統會隨機佈置 35 張牌，並自動避開任何初始鄰接的狀況，確保第一步由玩家主導。
• 計時與進度：畫面左上方顯示「剩餘牌數」，右上方則是「挑戰用時」。
• 結算：當盤面與牌堆皆清空時，即代表挑戰成功，系統將記錄您的總用時。
💡 獲勝小撇步
• 觀察空間：優先移動會產生「連鎖反應」的位置，利用補牌的隨機性來破局。
• 保留空位：不要急著填滿所有空格，保留移動的「活路」是通往勝利的關鍵。
• 花色記憶：在精簡模式中，注意剩餘的對子數量，避免最後關頭剩下互不相鄰的孤牌。
